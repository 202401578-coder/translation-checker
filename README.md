# 문장 사이 — 브라우저 의미 분석

독일어 등의 원문과 **한국어 번역만** 각각 입력하면, 다국어 문장 임베딩으로 대응 후보를 찾습니다. 중간 누락 이후의 연결을 복구하고 2:1 합쳐짐, 1:2 나뉨, 추가 및 의미 확인 대상을 표시합니다.

## 실행

Node.js 22.18 이상 권장.

```sh
npm ci
npm run dev
```

http://127.0.0.1:3000 에서 사용합니다. 최초 분석 시 Hugging Face의 `Xenova/paraphrase-multilingual-MiniLM-L12-v2` 양자화 모델(약 145MB)과 WASM 런타임을 다운로드합니다. 모델은 가능한 경우 브라우저 캐시에 저장됩니다. 문장 내용은 외부 API로 전송하지 않으며 Web Worker 안에서 분석합니다. 별도 서버나 API 키는 필요하지 않습니다. 기기 성능에 따라 분석 시간이 달라지며 최신 브라우저 사용을 권장합니다. 다운로드와 분석 중에는 진행 상태가 표시되며 취소할 수 있습니다.

## 사용 흐름

1. 왼쪽에 원문, 오른쪽에 한국어 번역만 붙여넣습니다.
2. 문장부호 기준 또는 한 줄 기준을 고르고, 필요하면 나눈 문장 목록을 확인합니다.
3. 문장 대응 검사를 실행하고 검토 필요 필터로 의심 부분을 살펴봅니다.
4. 직접 확인 표시, 해석 가리기, 검토표 저장/복사를 사용할 수 있습니다.

최대 입력은 각 100문장, 두 텍스트 합계 30,000자, 한 문장 1,000자입니다. TXT/Markdown 파일 업로드를 지원합니다. 입력이나 언어/분리 기준 변경 시 오래된 결과는 지워집니다. 입력과 확인 상태는 서버에 저장하지 않으므로 필요한 결과는 검토표로 저장하세요.

## 정확도와 한계

의미 유사도는 번역 정확도나 확률이 아닙니다. 대응 후보는 사람의 확인이 필요하며 부정어, 숫자, 고유명사 오역을 모두 검증하지는 않습니다. 정렬은 원래 순서를 따르므로 순서가 바뀐 번역, 세 문장 이상 합쳐짐, 반복되거나 비슷한 문장, 긴 문장에서 오판할 수 있습니다. 합쳐짐/나뉨은 결합 문장의 유사도가 개별 문장보다 높아지는 경우에만 제안합니다.

## 확인

Node 환경에서 모델 및 정렬 로직 확인:

```sh
npm run test:alignment
```

전체 번역, 누락 뒤 재정렬, 합쳐짐, 나뉨, 같은 문장 수에서 누락+나뉨, 무관한 문장, 빈 입력 및 문장 보존을 확인합니다. 테스트용 모델은 `.model-cache`에 저장됩니다. 브라우저 WASM 실행은 실제 배포 화면에서 별도 확인합니다.

개발 서버와 빌드 산출물 충돌 없이 빌드:

```sh
NEXT_DIST_DIR=.next-static NEXT_PUBLIC_BASE_PATH=/translation-checker npm run build
```
