# 독일어 학습 도구

원문과 원문·한국어 번역 혼합 텍스트를 비교하여 원문 문장의 누락, 유사 문장, 순서 변화, 추가 문장을 표시합니다. 한국어 번역 의미 자체를 검증하는 도구는 아닙니다.

## 사용

왼쪽에는 원문을, 오른쪽에는 원문과 한국어 번역이 함께 있는 텍스트를 입력하고 비교하기를 누르세요. 샘플 텍스트에는 의도적으로 한 문장이 빠져 있습니다. 단어 뜻 확인 페이지도 제공합니다.

입력은 브라우저 안에서 처리되며 서버에 저장되지 않습니다.

## 로컬 실행

```sh
npm ci
npm run dev
```

## GitHub Pages 빌드

```sh
NEXT_PUBLIC_BASE_PATH=/translation-checker npm run build
```

`out` 디렉터리가 정적 배포 결과입니다. 배포 브랜치는 `gh-pages`입니다.
